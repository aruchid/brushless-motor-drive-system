# 电机闭环控制仿真

## 当前实现

带抗积分饱和的 PI 速度控制与转动惯量模型；不包含三相换相或真实驱动。

这是可运行的数值基线原型，不等同于网站介绍中的完整系统。

## 输入契约

等间隔角速度目标数组，单位 rad/s。核心函数位于 `src/prototype.py` 的 `process`，可直接导入调用。默认命令运行固定种子合成样例，并在代码中断言预期效果；真实数据需由调用者按照函数形状约束传入。

## 快速运行

Python 3.11+。

```sh
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python src/prototype.py --output artifacts
python -m unittest discover -s tests -v
```

## 输出与验证

- `artifacts/result.png`：当前代码生成的结果可视化。
- `artifacts/metrics.json`：样例指标。
- `artifacts/results.npz`：结果数组，按图例顺序编号。
